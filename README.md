# きんこうバスナビ（錦江町のバス・試作）

錦江町のコミュニティバス（田代地区）と、鹿屋方面の路線バス・鹿児島中央駅直行バスの時刻と路線を、スマホで地図と一緒に見られるWebアプリ（PWA）の試作です。
地図・オフライン対応などの仕組みは「錦江町森林ナビ」「錦江町防災ナビ」と同じです。

公開URL：https://tockyocky12-droid.github.io/kinko-bus/

**試作中の非公式のものです。正式な時刻は、町の時刻表・鹿児島交通で確認してください。**

## できること（v1）

- 4路線（コミュニティバス・海岸線・中央線・直行バス）を色分けして地図に表示
- 地図のバス停を押すと「次のバス」と「あと何分」を表示。平日・土日祝（祝日も）を自動で判定
- 現在地から一番近いバス停を探す
- 便を押すと、その便の全バス停の時刻と、鹿屋での垂水方面との乗り継ぎを表示
- 路線別の時刻表（10月1日改定で変わった便は黄色）
- 圏外でも開ける（一度見た地図の画像は端末に保存。上限2000枚）

## データ

| データ | 入手先 | ファイル |
|---|---|---|
| 時刻 | 錦江町「錦江町関連バスの運行時刻表（R8.10.1改定分）」PDFから書き写し | `data/timetable.js` |
| バス停の位置 | 国土数値情報（バス停留所データ）令和4年度（国土交通省）を加工 | `data/stops.js` |
| 路線の道すじ | 国土数値情報（バスルートデータ）平成23年度（国土交通省）の線で、バス停どうしを道に沿ってつないだもの（`tools/route_lines.py`） | `data/stops.js` の LINE_PATHS |
| 年末年始などの運休 | 確かめられたものだけ（今は根占〜佐多間の12/30〜1/3）。お知らせの文も同じファイル | `data/special.js` |
| 背景の地図 | 地理院タイル（淡色地図） | 表示のたびに配信元から |

**ダイヤ改定のときは `data/timetable.js` だけを直す。** 直し方はファイルの先頭に書いてある。
路線の道すじは、国土数値情報（バスルート）の道路の線でバス停どうしをつないだ目安（tools/route_lines.py、直行バス・空港バスは tools/route_extra.py）。直行バスの垂水港〜鴨池港はフェリーなので点線（FERRY_SEGS）。

## 守ること

- 更新のたびに `sw.js` の `VER` と `index.html` の `APP_VER` を同じ番号で上げる。
- 地図画像は `crossOrigin='anonymous'` で読み、opaque（中身の見えない形）では保存しない。
- 端末の記録は、同じサイトの森林ナビ・防災ナビと混ざらないよう `bus:` を頭に付けて保存する。
- 変更後は `tools/test_app.py`（Playwright）で動作を確認してから公開する。
